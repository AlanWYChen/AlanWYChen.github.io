# Mobile Authentication

## Core flows

Consider:
- email/password
- Google sign-in
- Sign in with Apple
- passkeys
- OAuth/OIDC
- MFA
- biometric reauthentication
- secure token refresh
- logout
- logout all sessions
- account linking
- account deletion
