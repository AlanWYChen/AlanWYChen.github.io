# Backend Authentication and Identity

The backend is the authoritative boundary for identity and authorization.

Support applicable mechanisms:
- session cookies
- JWT access tokens
- OAuth/OIDC
- Google identity
- Apple identity
- service-to-service auth
- API keys
- mTLS
- passkey/WebAuthn verification
- MFA
