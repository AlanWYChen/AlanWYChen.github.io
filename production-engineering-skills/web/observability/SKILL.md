# Web Observability

## Frontend

Capture:
- runtime exceptions
- unhandled promise rejections
- failed API requests
- route/page failures
- Web Vitals
- release version
- environment

## Server/API

Use:
- structured logs
- request IDs
- correlation IDs
- latency/error metrics
- tracing for cross-service flows

Never log:
- passwords
- auth tokens
- private keys
- unnecessary sensitive personal data

Alerts should be actionable and should distinguish user errors from system failures.
